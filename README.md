# Plantory 🌿

**Plantory** — веб-приложение для поиска растений и проверки их совместимости при совместном выращивании.

## Возможности

- 🌱 **Каталог растений** — просмотр растений с описаниями.
- 🔎 **Поиск** — поиск по названию, научному имени и синонимам.
- 🪴 **Страница растения** — отдельная страница с информацией о выбранном растении.
- 🤝 **Совместимость растений** — информация о совместимых и несовместимых растениях.
- ⭐ **Избранное** — интерфейс для работы с избранными растениями.
- 📱 **Адаптивный интерфейс** — поддержка мобильных и настольных экранов.

## Установка и запуск

### Требования

- [Node.js](https://nodejs.org/)
- npm

### 1. Клонирование репозитория

```bash
git clone https://github.com/GrowMySkill/plant-compatibility.git
cd plant-compatibility
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск приложения

```bash
npm start
```

После запуска открой в браузере:

http://localhost:3000/

## Работа с данными

Исходные данные растений хранятся в `backend/data/plants.json`, а приложение использует базу данных SQLite.

Чтобы импортировать растения из JSON в базу данных, выполни:

```bash
npm run import:plants
```

Перед импортом скрипт создаёт резервную копию базы данных. Перед повторным импортом рекомендуется проверить актуальность исходного JSON и резервной копии.

Для проверки связей между растениями предусмотрена команда:

```bash
npm run check:relationships
```

## Разработка

Основные файлы интерфейса:

- `frontend/index.html` — главная страница и каталог.
- `frontend/plant.html` — страница отдельного растения.
- `frontend/js/app.js` — логика каталога и поиска.
- `frontend/js/plant.js` — логика страницы растения.
- `frontend/css/style.css` — стили приложения.

Основные файлы серверной части:

- `backend/server.js` — сервер и API.
- `backend/db.js` — работа с базой данных.
- `backend/import-plants.js` — импорт данных растений.

## База данных

Проект использует SQLite для хранения информации о растениях, синонимах, советах и связях совместимости.

Основная база данных находится в `backend/data/plantory.db`. Резервные копии базы также хранятся в `backend/data/`.

База данных и её резервные копии включены в Git-репозиторий, чтобы сохранять изменения и переносить данные вместе с проектом.

**Важно:** перед внесением изменений в базу рекомендуется создать резервную копию и проверить состояние Git, чтобы случайно не перезаписать актуальные данные.
